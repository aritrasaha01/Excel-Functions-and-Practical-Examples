# Excel Functions and Practical Examples

Welcome to my Microsoft Excel learning repository!

This repository documents my journey of learning and practising Microsoft Excel, with a focus on essential functions, formulas, data analysis, and practical business applications.

## What You Will Find Here

I will progressively add practical examples and exercises covering the following topics:

### 1. Lookup and Reference Functions
- VLOOKUP
- XLOOKUP
- INDEX and MATCH

### 2. Logical Functions
- IF
- IFS
- AND
- OR

### 3. Mathematical and Statistical Functions
- SUM
- AVERAGE
- COUNT
- COUNTA

### 4. Conditional Functions
- SUMIF and SUMIFS
- COUNTIF and COUNTIFS
- AVERAGEIF and AVERAGEIFS

### 5. Data Management
- Data Validation
- Conditional Formatting
- Sorting and Filtering

### 6. Data Analysis
- Pivot Tables
- Charts and Visualisation

### 7. Macros
- Recording Macros
- Running Macros
- Creating Buttons to Execute Macros

## Learning Approach

For each topic, I aim to provide:

- Practical examples
- Sample datasets
- Excel formulas and explanations
- Screenshots of results
- Downloadable Excel practice files

## Objective

To develop practical Microsoft Excel skills and demonstrate their application in business analysis, reporting, and decision-making.
